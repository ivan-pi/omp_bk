# Bundled examples and scripts

| Path | What | Test result (Arc A770 = DG2, UHD 750 = Gen12LP) |
|---|---|---|
| `examples/cm_ocl.hpp` | the skill's OpenCL C++ bindings helpers (not a CM API): `pick_gpu` (Intel GPU accepting SPIR-V, largest first, `$CM_DEVICE` name preference), `load_program` (.spv/.bin/.cpp with the right options and build log), `has_lsc`, `report` | used by every OpenCL host |
| `examples/vadd_genx.cpp` + `host_ocl.cpp` | minimal kernel (chunk loop); CLHPP host for .spv/.bin/.cpp | PASS on A770 and UHD 750 |
| `examples/cm_sycl.hpp` + `host_sycl.cpp` | the default SYCL host helpers (`make_queue`, `load_program` for .spv/.bin/.cpp, `program::kernel`, `launch`, `elapsed_ms`, `ip_version`, `has_lsc`) and the vadd host | PASS on A770 and UHD 750: .spv/.bin on L0 and OpenCL; .cpp under `cm_run` |
| `examples/patterns_genx.cpp` + `host_patterns.cpp` | transpose8 (2D threads, matrix select), hist256 (atomics), clamp_scale (SIMD CF vs merge), chunk_sum (cm_sum, scalar scatter), reverse32 (iselect, replicate), group_sum (SLM + barrier), vadd_svm (stateless) | all PASS on A770 and UHD 750 |
| `examples/linear_genx.cpp` + `host_linear_ocl.cpp` | the paper's linear filter: 2D media block I/O, 9 selects | PASS bit-exact on A770 and UHD 750 |
| `examples/dpas_genx.cpp` + `host_dpas.cpp` | `cm_dpas` fp16 8x8x16 with VNNI packing | PASS on A770 (needs XMX) |
| `examples/cmrt/hello_world_genx.cpp` + `hello_world.cpp` + `run_cmrt.sh` | the CM runtime flow (CmDevice ... CmEvent), with adapter selection, a thread space, the GPU print buffer and an output buffer check; `va_stub/` for builds without libva-dev | needs `CSDK_DIR` (2021 SDK); PASS on UHD 750 (hardware runtime) and emulated on the CPU; DG2 (A770) is not supported by the CM runtime |
| `examples/emu/host_emu.cpp` + `run_emu.sh` | `vadd` on the CPU through the 2021 SDK emulator (shim layer, kernel compiled by g++) | PASS (CPU) with `CSDK_DIR`; skipped without |
| `examples/spmv_genx.cpp` + `host_spmv.cpp` | CSR SpMV from the CM paper/talk: one thread per row, DWord-aligned slice reads, `merge` of the tail to column 0 of a zero-padded x, gather, `cm_dp4` + `cm_sum`, slice width 8/16/32 chosen per row | PASS bit-exact, A770 0.20 ms and UHD 750 2.06 ms (100k rows, 3.2 M nonzeros) |
| `examples/gesv_genx.cpp` + `host_gesv.cpp` | batched small dense solves with partial pivoting (LAPACK sgesv: L/U in A, 1-based ipiv, X in B), any N = 1..32 (`-DGESV_N`, `-DGESV_NRHS`): one CM thread per system in registers; column-major A loaded as A^T rows (pivot search = contiguous row, runtime row swap = indirect register-column swap); per-step trailing update = one `replicate` outer-product mad on an exactly sized region (k unrolled via `if constexpr`). Odd N: DWord-aligned loads, exact scattered stores, register rows padded to 8/16/32 floats (31x31 had ~700 spill instructions unpadded). N > 16 needs `-double-GRF`: the indirectly addressed matrix must be one contiguous register block. cuSolverDx Thread/Block mapping: `references/simt-vs-simd.md` §5 | PASS for N = 3, 5, 7, 8, 13, 16, 24, 31, 32 (pivots identical to the CPU reference in every system, backward error <= 3e-7). A770: 16x16 x4 rhs 822 GFLOP/s at 451 GB/s (memory-bound), 32x32 830-1035 GFLOP/s, 31x31 992, 7x7 309. UHD 750 up to N = 16 (no large-GRF mode), 28-35 GB/s |
| `examples/gesvb_genx.cpp` (same host, `lanes` argument) | the same solve as cuSolverDx's **Thread** operator: 16 systems per CM thread, one per SIMD lane, structure-of-arrays registers; per-lane pivoting = compare + `merge`, per-lane row swaps = `merge` over candidate rows (skipped by `any()`); the thread's 16 systems are contiguous, so block reads + in-register AoS→SoA transpose (gathers capped at ~225 GB/s) | PASS N = 2..8 (incl. a partial last thread). A770, 1M systems: faster than one-system-per-thread up to N = 7 (N=2 3.8x, N=3 2.5x, N=4..6 1.6-1.7x), even at N = 8; N >= 6 needs `-double-GRF`. Both solvers are memory-bound alone: their value is inside fused "mega-kernels" that keep the systems in registers |
| `examples/traits_genx.cpp` + `host_traits.cpp` | cuSolverDx-style descriptor `decltype(Size<16,16,4>() + Precision<float>() + Function<posv>() + ...)` configuring a kernel: cmc is fixed at C++17 (`-std=` rejected), with a minimal `std` | PASS on A770 |
| `examples/lsc_genx.cpp` + `host_lsc.cpp` | LSC API: 256 B blocks, cache hints, flat-pointer blocks, SIMD16 gather, atomics, vs the legacy OWord copy | PASS on A770 from .spv, .bin and CM source; skipped on Gen12LP (no LSC) |
| `examples/target_genx.cpp` + `host_target.cpp` | target macros: the binary reports `CM_GENX`/IP/`CM_HAS_*`, the host compares with the GPU; `copy_best` picks LSC or legacy blocks | PASS on A770 and UHD 750 (also with the 2021 cmc) |
| `examples/specconst_genx.cpp` + `host_specconst_ocl.cpp` | SPIR-V specialization constants (`cm_spec_constant`, `setSpecializationConstant`) | PASS on A770 and UHD 750 |
| `examples/scan_genx.cpp` + `host_scan.cpp` | inclusive and exclusive prefix sums: `scan16_demo` (the OpenMP-article example in registers: Hillis-Steele log-step on `select` regions via `if constexpr`, exclusive = inclusive shifted one lane), a full-array reduce-then-scan (chunk sums → one-thread exclusive scan of the sums → rescan with carry), a single-pass decoupled look-back scan (atomic tickets, flags, fences, a 16-wide vectorized look-back with `cm_pack_mask`/`cm_fbh`, bounded spins), plus a copy reference | PASS; A770 64M ints: reduce-then-scan 2.04 ms (1.65 x a copy), look-back 28.6-90 ms (correct, not competitive); UHD 750 1.44 x copy |
| `examples/argmax_genx.cpp` + `host_argmax.cpp` | argmax (first index of the maximum) for int32 and double: stage 1 = per-lane (max, index) registers updated with compare + `merge`, 2 x 128 B reads in flight; stage 2 = reduction tree over SoA partials; doubles compared via order-preserving integer keys (no FP64 on DG2); includes a read-only reference kernel | PASS; A770 int32 415 GB/s, double 402 GB/s end to end vs 428 GB/s reference kernel (256 MiB arrays); UHD 750 43 GB/s (= its read-only reference) |
| `examples/esimd/*.cpp` | upstream ESIMD examples (fixed), plus `subgroup_vs_esimd.cpp` (the same 16-wide scan and sum as a SYCL sub-group kernel and as ESIMD, bit-identical when run on an A770) and `pipeline_functor.cpp` (functor kernel with fused stages, then a lambda kernel) | PASS on A770, see `references/esimd.md` |
| `scripts/cm_build.sh` | cmc → SPIR-V → ocloc, `-k` keeps .i/.ll/.spvasm/IGC dumps (the 2021 cmc too, via `CSDK_DIR`) | |
| `scripts/install_cm_toolchain.sh` | user-space cmc + matched IGC/ocloc/OpenCL and Level Zero, for systems whose driver doesn't come from Intel's repository (wrappers `cmc`, `ocloc-cm`, `cm_run`) | all examples PASS with it on A770 and UHD 750 |
| `scripts/run_examples.sh` | builds and checks everything; `-s` adds SYCL, `-g <name>` picks the GPU by a name substring | |
| `references/language.md`, `memory.md`, `pipeline.md`, `targets.md`, `assembly.md`, `esimd.md`, `simt-vs-simd.md`, `documentation.md` | detailed references; `documentation.md` compares the GitHub docs, the 2021 SDK docs and the 2019 Intel tutorial zip | |
| `references/legacy-sdk.md` | the 2021 CM SDK and the 2022 GitHub release: what only they provide (CM-runtime `.isa`, CPU emulation), the `-mcpu` cmc, its tested bugs, its docs | |

The results are from `scripts/run_examples.sh` runs on an Arc A770 (DG2) and a UHD 750 (Gen12LP); other GPUs of the same generations should behave alike, but are untested.
